# PollApp

Angular-Projekt mit TypeScript und separaten HTML- und CSS-Dateien.

Abhängigkeiten installieren:

```sh
npm install
```

Entwicklungsserver starten:

```sh
npm start
```

Die Startseite ist unter `http://localhost:4200/` erreichbar, der Thumbnail unter `/thumbnail`.

Build erstellen:

```sh
npm run build
```
